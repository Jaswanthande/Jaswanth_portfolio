## ⚡ Quick Start: Running in VS Code

You can run this project in **VS Code** using any of the following simple methods:

### Option 1: Using the Integrated Terminal (Recommended)
Open VS Code terminal (`Ctrl + \``) inside this directory and run:

```bash
npm run dev
# or
node serve.js
```
The server will start at `http://localhost:3000` and automatically open your default browser.

---

### Option 2: Press `F5` in VS Code (One-Click Debugger)
1. Open this folder in VS Code.
2. Press **`F5`** (or go to **Run and Debug** in the left sidebar and click the Green Play button).
3. The portfolio will immediately launch in **Google Chrome** or **Microsoft Edge**.

---

### Option 3: VS Code Live Server Extension
1. Install the **Live Server** extension (by Ritwick Dey) in VS Code.
2. Right-click `index.html` in the file explorer and select **"Open with Live Server"**.
3. Live preview launches instantly at `http://127.0.0.1:5500`.

---

### Option 4: Python Built-In Server
If you prefer Python:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in any web browser.
